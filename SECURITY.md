# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/AIWatercolorGenerator/ai-watercolor-generator-mcp/security/advisories/new).

Do not open a public issue containing API keys, Authorization headers, private image URLs, sensitive images, personal information, or exploit details. Revoke any API key that may have been exposed before sending a report.

Include the affected package version, Node.js version, MCP client, reproduction steps, and impact. Use redacted values or a dedicated low-credit test key.

## Supported versions

Only the latest published version receives security fixes. This package sends user-approved requests to the hosted AI Watercolor Generator API and does not store credentials or task history locally.
